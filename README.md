# Incas & Uyuni 2026

Site do roteiro da expedição de moto Governador Valadares → Peru → Bolívia → Governador Valadares.

- `index.html` — o site (abre direto, sem build)
- `data.js` — todos os dados da rota (cidades, km, avisos). Para mudar o roteiro, edite aqui.
- `gerar-rotas.html` — gera `routes.js` com o traçado real pelas estradas
- `incas-uyuni-2026.gpx` — rota para OsmAnd / BMW Motorrad Connected

Publicado no Netlify, sem etapa de build (diretório de publicação: raiz).

Feito por Node Data.
